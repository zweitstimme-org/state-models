# Data

- **input/** — Manually maintained CSVs (edit only by hand). Numbered for pipeline order.
  - `01_state-election-results.csv` — State election results
  - `02_state-cabinets.csv` — State cabinet / coalition data
  - `03_federal-election-results.csv` — Federal election results

- **output/** — Generated by `code/01_build_data.R` (gitignored). Do not edit.
  - `01_state-polls.csv`, `01_state-polls-diagnostics.txt` — State polls (from API)
  - `02_state-leads.csv` — State poll leads
  - `03_federal-polls.csv` — Federal polls (from same API as state polls)
  - `04_federal-leads.csv` — Federal poll leads
  - `05_full_data.RData` — Full modeling dataset
- **output/model/** — Model estimation outputs (RDS) from `code/02_estimate_model.R`.
- **output/forecast_data.RData** — From `code/03_forecast.R` (Part 1; also used by forecast figures).
- **output/forecast/** — Forecast objects and CSVs from `code/03_forecast.R` (Part 2).

**Full pipeline (data + model + validation + forecast):** from project root run  
`Rscript run_everything.R`  
See comments in `run_everything.R` for manual inputs and election list.

**Data only:** `Rscript code/01_build_data.R`
